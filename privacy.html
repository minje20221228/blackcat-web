Local Storage

Build Data Saved In The Browser

The build editor stores selected builds and ownership metadata in the browser so visitors can keep working across visits. Build contents, the signed-in local login ID, and ownership identifier are saved locally on the visitor’s device; public build cards show only the nickname, and this site does not run a separate account database for those builds.

로컬 저장소

브라우저에 저장되는 빌드 데이터

빌드 편집기는 선택한 빌드와 소유자 메타데이터를 브라우저에 저장해 방문자가 이어서 작업할 수 있게 합니다. 빌드 내용, 로그인한 로컬 로그인 아이디와 소유자 식별자는 방문자 기기에 로컬로 저장되며, 공개 빌드 카드에는 닉네임만 표시하고 이 사이트는 해당 빌드를 위한 별도 계정 데이터베이스를 운영하지 않습니다.

Local Login

Build Ownership Through Local IDs

When visitors use the build login, they enter a local login ID directly in the browser. Build Lab uses that ID only to show a nickname and to check whether the same local ID is editing or deleting a locally saved build.

No external account token is requested for this local login. Build Lab stores only the minimal local session fields needed for the build editor on the visitor’s device.

로컬 로그인

로컬 아이디로 구분하는 빌드 소유자

방문자가 빌드 로그인을 사용하면 브라우저에서 로컬 로그인 아이디를 직접 입력합니다. Build Lab은 이 아이디를 표시용 닉네임 생성과 같은 로컬 아이디가 저장된 빌드를 수정 또는 삭제하는지 확인하는 용도로만 사용합니다.

이 로컬 로그인에는 외부 계정 토큰을 요청하지 않습니다. Build Lab은 방문자 기기의 빌드 편집기 세션에 필요한 최소 로컬 세션 필드만 저장합니다.

Advertising

Google AdSense Disclosure

This site may use Google AdSense to display ads. Google and its partners may use cookies or similar technologies to serve and measure ads based on visits to this and other websites. Visitors can learn more about how Google uses information from sites or apps that use its services through Google’s own policies and controls.

AdSense loading is intentionally limited to pages with original site guidance and policy information. Reference and tool screens that primarily display card, relic, potion, or patch data are kept free of Google-served ads so advertising is not paired with thin copied reference content.

If personalized advertising becomes active, visitors should review Google’s advertising settings and privacy choices for the most current controls available to them.

광고

Google AdSense 고지

이 사이트는 Google AdSense를 통해 광고를 표시할 수 있습니다. Google과 그 파트너는 쿠키 또는 유사 기술을 사용해 이 사이트 및 다른 사이트 방문 기록을 바탕으로 광고를 제공하거나 측정할 수 있습니다.

AdSense 로딩은 독자적인 사이트 해설과 정책 정보가 있는 페이지로 제한합니다. 카드, 유물, 포션, 패치 데이터가 중심인 레퍼런스 및 도구 화면에는 Google 게재 광고를 두지 않아 얇은 복제성 콘텐츠와 광고가 함께 노출되지 않게 합니다.

개인 맞춤 광고가 활성화되는 경우, 방문자는 Google의 광고 설정과 개인정보 관련 안내를 통해 최신 제어 옵션을 확인해야 합니다.
